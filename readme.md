# 全体
## ファイル構成について
使っていただくファイルは主に2つです。
- model_train.ipynb: モデルの学習を行うファイルです。
- store_output.ipynb: モデルの出力を保存するファイルです。

## 流れ
1. DAとの比較
ランダムDAの結果と比較して、「良い」ものかどうかを検証する。また、ランダムDAの凸結合で表せるものでないことを証明する方法を考える

2. モデルの解釈
出力された中で良さそうなモノについて、どのようなアルゴリズムかを解釈する

3. 一般化
nを増やす。ここまでできたらめっちゃ嬉しい
