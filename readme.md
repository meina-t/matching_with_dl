## ファイル構成について
使っていただくファイルは主に2つです。
- model/model_train.ipynb: モデルの学習を行うファイルです。
- output/store_output: モデルの出力を保存するファイルです。

## モデルの学習
Settings 3つ目のブロックでルートディレクトリを調整してください。

Train 2つ目のブロックが重み付けです。[pi, qi]にはpiとqiの組み合わせに対する重みが設定されます。

＊調整方法は要議論*

## モデルの出力
一定以上の出力があった場合、モデルを保存します。

Train　最後のブロックのモデル名を調整して、モデルを保存してください。同時に、その時のlambda_weightsも記録してください。
